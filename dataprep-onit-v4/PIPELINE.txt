DATAPREP ONIT — FULL PIPELINE
==============================

RAW DATA
   |
   v
[1. BULK MERGE]          -- optional, skip if single file
   stack same-structure files into one
   pre-check column mismatches before merging
   |
   v
[2. CLEAN]               -- always required
   standardize column names
   remove duplicates
   fix data types
   handle missing values (flag / drop / fill)
   detect outliers (IQR)
   trim whitespace
   |
   v
[3. IMPUTE]              -- if gaps remain after cleaning
   Mean / Median / Mode  → fast, dumb, small gaps
   KNN                   → smart, uses other columns to estimate
   CTGAN                 → synthetic rows, large missing blocks
   |
   v
[4. PREDICT]             -- train on clean history, predict next period
   select target column (what to predict)
   select feature columns (what to use)
   select model (linear / random forest / gradient boost)
   train → evaluate → predict next N days/weeks/months
   save prediction as file
   |
   v
[5. VALIDATE]            -- when real data arrives
   upload real data for the predicted period
   compare prediction vs reality
   accuracy score + error report
   iterate: retrain model with new real data
   |
   v
CLEAN OUTPUT + REPORT + TEAMS NOTIFICATION
